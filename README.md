# Stacker

**Stacker** is a free, unrestricted multi-effect audio plugin featuring 22 built-in effects, serial effect stacks, parameter distribution curves, LFOs, envelope followers, and macros.

Website: **[sarendipitee.github.io/stacker](https://sarendipitee.github.io/stacker/)**

---

## Downloads

Download installers and packages directly from the [GitHub Releases](https://github.com/sarendipitee/stacker/releases) page.

- **macOS (Apple Silicon arm64)**: Installer `.pkg` (VST3 / AU / CLAP / Standalone)
- **Windows (x64)**: Installer `.exe` or portable `.zip` (VST3 / CLAP / Standalone)
- **Linux (x64)**: Portable `.tar.gz`, `.deb`, or `.rpm` (VST3 / CLAP / LV2 / Standalone)

Check [SHA256SUMS.txt](https://github.com/sarendipitee/stacker/releases/latest/download/SHA256SUMS.txt) in each release for file integrity.

---

## Update Manifest

Stacker checks for updates in the background against [`latest.json`](https://raw.githubusercontent.com/sarendipitee/stacker/main/latest.json) and displays an unobtrusive notification when a new version is available.
